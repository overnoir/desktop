**Overnoir** is a cross-platform desktop overlay application. It displays information about Discord voice channel activity, Kick streamer status, and system metrics as a always on top floating panel.

Built with **Nuxt 4 + Vue 3** on the frontend and **Tauri v2 + Rust** on the backend.

## Features

### Discord Overlay

See who is in your current voice channel, their speaking and mute/deafen states, avatars, and server info.

### Kick Streamer Status

Follow your favorite Kick streamers and see who is live with avatars and stream categories. Open streams in a dedicated viewer window.

### System Monitoring

CPU usage, memory consumption, network bandwidth (upload/download), and battery status.

### Multi-Language

Available in English, Turkish, German, French, Spanish, and Portuguese.

### Highly Customizable

- Size, position, and orientation
- Opacity and corner radius
- Background and gap settings
- Drag handle and settings button toggles
- Content protection (hidden from screen recordings)
- Always on top / ignore cursor events
- Auto-start on system boot
